# Ogaga Iyara Nicholas Portfolio

A modern single-page portfolio for Ogaga Iyara Nicholas, built with React,
TypeScript, Tailwind CSS, Framer Motion, and React Scroll.

## Features

- Responsive portfolio layout with hero, about, skills, projects, testimonials,
  contact, and footer sections.
- Light and dark theme toggle with persisted user preference.
- Tailwind CSS styling with no Sass source files.
- Accessible navigation, labeled form controls, keyboard focus states, and
  external-link safety attributes.
- Project data and testimonial content stored in typed data files.

## Scripts

```bash
npm start
npm run build
npm test
```

`npm run build` creates the production bundle in the `build` directory.
